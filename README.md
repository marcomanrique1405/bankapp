# BankApp

Backend banking application built with Java and Spring Boot.

## Project overview

BankApp is a portfolio project for practicing backend development and banking domain concepts. The codebase uses Spring Boot, Spring Security with JWT, PostgreSQL, and Docker.

## Development workflow

Development changes are integrated into the `develop` branch:

1. Create a new branch using the `task/` prefix.
2. Make a focused change and commit it with a descriptive message.
3. Open a pull request targeting `develop`.
4. Review and merge the pull request after the required checks pass.

See [`docs/development-workflow.md`](docs/development-workflow.md) for more details.
